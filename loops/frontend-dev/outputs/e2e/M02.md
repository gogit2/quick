## E2E-M02-06 - Search, filters, sort send the right parameters (US-TSK-05, US-TSK-06, FR-02)

Steps
1. Search (checked in iteration 1, not repeated in this pass): typing `RENT` into `tasks-search-input` sent `GET /api/tasks?q=RENT&sort=CREATED_DESC&archived=false` after the 300 ms debounce.
2. Select in order (this pass), reading each request from the resource timing log:
   - `tasks-filter-status` = Done → `status=DONE`
   - `tasks-filter-priority` = High → `priority=HIGH`
   - `tasks-filter-due` = Overdue → `due=OVERDUE`
   - `tasks-sort` = Due date (earliest first) → `sort=DUE_DATE_ASC`
   - `tasks-filter-due` = No due date → `due=NO_DUE_DATE`
   - `tasks-sort` = Oldest → `sort=CREATED_ASC`
   The combined requests are cumulative and all carry `archived=false`.
3. `tasks-show-archived` on → `archived=true`.
4. Click `tasks-clear-filters`: request returns to `GET /api/tasks?sort=CREATED_DESC&archived=false`, selects reset to "All statuses / All priorities / Any due date / Newest", search empty.

Test ids used: `tasks-search-input`, `tasks-filter-status`, `tasks-filter-priority`, `tasks-filter-due`, `tasks-sort`, `tasks-show-archived`, `tasks-clear-filters`.
