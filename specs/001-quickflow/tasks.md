# Tasks: QuickFlow

**Input**: specs/001-quickflow (spec.md, plan.md, data-model.md, contracts/openapi.yaml, requirements/DECISIONS.md)
**Organization**: by milestone (vertical slices M01-M07), each with BE and FE tasks built in parallel. Tags: BE or FE (exactly one per task), user story ids `US-AREA-NN`. `scripts/split-tasks.py` splits this file into `loops/backend-dev/outputs/Mxx-*.md` and `loops/frontend-dev/outputs/Mxx-*.md`.
**Rules**: tasks of one role run in file order; BE and FE share only `contracts/openapi.yaml`. Acceptance ids (AC-Mxx-nn for curl, E2E-Mxx-nn for Playwright) are defined in `acceptance.md`.
